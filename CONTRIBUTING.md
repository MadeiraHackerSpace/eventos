# Guia de Gestão e Contribuição — Domingos Hackers

Este guia orienta administradores e associados sobre como manter a engrenagem de eventos do **Madeira Hacker Club** funcionando de forma transparente e colaborativa.

---

## 🛠️ Papel dos Administradores

1. **Triagem de Issues:**
   - Quando alguém abrir uma issue com o título `[Proposta]: ...`, um administrador deve responder agradecendo e avaliando a viabilidade (materiais, espaço, alinhamento de data).
   - Adicionar a label correspondente (`confirmado`, `aguardando-data`, `em-planejamento`).

2. **Gerenciamento do Projeto (GitHub Project / Kanban):**
   - Recomendamos criar um projeto na organização chamado **"Domingos Hackers 2026"**.
   - Fluxo de colunas sugerido:
     1. `💡 Sugestões / Ideias da Comunidade`
     2. `📝 Em Definição (Facilitador / Conteúdo)`
     3. `📢 Agendado & Divulgação`
     4. `🚀 Próximo Encontro`
     5. `✅ Realizado (Criar Ata)`

3. **Divulgação Semanal:**
   - Na quinta-feira anterior ao domingo:
     - Gerar o card/texto simples para disparo no WhatsApp e mídias sociais.
     - Atualizar a tabela no `CALENDARIO.md` via Pull Request ou commit direto.

4. **Fechamento do Encontro (Ata):**
   - Um participante ou administrador abre uma issue com o template `📝 Registro / Ata` ou faz um PR adicionando um arquivo em `encontros/YYYY/YYYY-MM-DD.md`.
   - Isso mantém a memória do clube viva e ajuda na prestação de contas com apoiadores e comunidade.

---

## 💡 Como Qualquer Membro Pode Participar

- Propor palestras, oficinas e mutirões via [Issues](../../issues).
- Sugerir compras de equipamentos ou temas de estudo.
- Submeter melhorias para a documentação e organização de eventos via Pull Requests.
